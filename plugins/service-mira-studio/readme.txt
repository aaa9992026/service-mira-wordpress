== Installation ==
1. Back up current staging WordPress and keep the previous plugin ZIP.
2. WordPress staging > Plugins > Add Plugin > Upload Plugin. Upload the ZIP and replace previous plugin.
3. Open Appearance > Service Mira Studio. Preserve selected published pages and hero image ID 832.
4. Keep homepage and inner page design switches on for staging; save.
5. Clear caches, then test desktop/mobile, menu, service links, price page, form display, legal pages and privacy consent link.
6. Client must confirm legal wording, prices and mail/submission behavior before production. Never push staging into production without approval.

== Rollback ==
Deactivate Service Mira Studio or turn both opt-in design switches off. No WordPress content or existing quotation-plugin code is overwritten.
